# Ретранслятор Vellia Mail

Необязательный сервер для Linux. Телефон и без него получает почту, пока приложение открыто, и иногда в фоне. Этот сервер нужен только если письмо должно приходить на iPhone почти сразу после того, как оно попало на почтовый сервер.

Телефон не отдаёт сюда пароли из Связки ключей. Он один раз присылает адрес APNs. Отдельный процесс на сервере сам входит в почту по паролю приложения, который вы кладёте в файл на VPS, и просит ретранслятор разбудить телефон.

Нужны Node.js 22, домен с HTTPS (иначе iPhone не отправит регистрацию) и ключ APNs `.p8` из Apple Developer → Keys → Apple Push Notifications service.

```bash
sudo mkdir -p /opt/vellia-relay /etc/vellia
sudo cp server.mjs watch.mjs /opt/vellia-relay/
sudo cp env.example /etc/vellia-relay.env
sudo cp vellia-relay.service vellia-watch.service /etc/systemd/system/
```

В `/etc/vellia-relay.env` заполните секрет, Team ID, Key ID и путь к `.p8`. В `/etc/vellia-watch.env` — тот же секрет и ящики. Пароль в этом файле — пароль приложения Mail.ru или Gmail, права на файл `600`.

Перед Caddy или nginx сервер слушает только `127.0.0.1:8787`. Пример сайта — `Caddyfile.example`. В приложении, в разделе «Уведомления», укажите `https://ваш-домен` и тот же секрет.

Первый проход наблюдателя запоминает уже лежащие непрочитанные и молчит. Сообщение уходит со следующего нового письма. Проверка примерно раз в минуту, это не мгновенный IMAP IDLE.
