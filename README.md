# Vellia Mail

Почта для Vellia Hotels & Restaurants на iPhone. Несколько ящиков в одном списке, фильтры и шаблоны в духе The Bat!, интерфейс по-русски, по-испански и по-английски.

Демонстрационный ящик `hola@vellia.test` уже лежит в приложении: брони, счета и гости Торревьехи. Это выдуманные письма, чтобы можно было потрогать экран до подключения настоящей почты. Их можно удалить в настройках.

## Почему именно так, и без Mac

Собрать приложение можно в облаке Expo (EAS Build) с Linux, Windows или чужого компьютера. Apple подписывает сборку на своих серверах, вы входите в Apple ID в браузере, когда программа об этом попросит. Xcode и Mac не нужны.

Движок почты написан на TypeScript и живёт в этом репозитории:

- Gmail подключается через Google: в Связке ключей остаётся ключ доступа, обычный пароль не вводится. Письма ходят через Gmail API.
- Mail.ru, List.ru и любой другой сервер — по IMAP и SMTP поверх TLS. Для этого в сборке есть модуль `react-native-tcp-socket`. Из‑за него приложение не запускается в Expo Go: на телефон ставится своя сборка через TestFlight.
- Письма и правила лежат в SQLite на телефоне. Пароли и ключи Google — только в Связке ключей iOS (`AFTER_FIRST_UNLOCK`, чтобы фоновая проверка тоже могла их прочитать). В базу и в текст ошибок секреты не записываются.
- Отдельный Swift-модуль с MailCore2 не используется: его тяжелее собирать в облаке, а протокол IMAP здесь покрыт тестами на поддельном сервере.

## Что умеет первая версия

- Несколько ящиков сразу: четыре Gmail и почта Mail.ru / List.ru, плюс свой сервер.
- Общий список входящих и папки каждого ящика. Чтение, ответ, ответ всем, пересылка, новое письмо, вложения до 20 МБ, выбор ящика отправителя.
- Поиск по уже скачанным письмам и запрос на сервер.
- Правила на телефоне: отправитель, тема, ящик и другие поля; папка, флажок, «прочитано», цвет строки. Папки создаются на телефоне, на сервере письма не перекладываются. Отметки «прочитано» и флажок уходят и на сервер.
- Шаблоны с подстановками `{имя}`, `{дата}`, `{время}`, `{тема}`, `{мояпочта}`, `{аккаунт}` и теми же словами по-испански и по-английски.
- Подпись у каждого ящика.
- Проверка почты каждые три минуты, пока приложение на экране, и заявка в фоновую очередь iOS.

## Чего оно не обещает

iOS не даёт почтовому приложению висеть открытым после того, как вы его закрыли. Фоновая проверка (`BGTaskScheduler`) запускается, когда система сама решит: часто это пятнадцать минут и дольше, иногда несколько часов, в режиме энергосбережения может не случиться вовсе. Мгновенное уведомление без своего сервера iOS не отдаёт.

В папке `relay/` лежит необязательный ретранслятор для своего Linux. Пока его нет, почта всё равно работает. Пока приложение открыто, новые письма ищутся сами.

Другие границы этой версии:

- Письмо в HTML показывается как текст.
- Правила не двигают папки на сервере.
- На телефон скачиваются последние письма папки, не весь архив за годы.
- Вход Google в режиме Testing просит войти снова примерно через семь дней. Так устроен Google, пока согласие на Gmail не прошло их проверку. Запасной путь — пароль приложения и IMAP, он не протухает.
- Учётная запись Apple Individual пускает во внутренний TestFlight только владельца. Посторонних можно пригласить только после проверки бета-версии Apple.
- В браузере открывается интерфейс и демонстрационные письма. Настоящий IMAP, Связка ключей и уведомления есть в сборке для iPhone.

## Посмотреть интерфейс на компьютере

Нужен Node.js 22.

```bash
npm install
npm test
npm run web
```

Откроется `http://127.0.0.1:43123`. В браузере можно пройти входящие, правила, шаблоны и черновик письма. Отправка и проверка Mail.ru здесь откажутся: сокет открывается только на телефоне.

## Что проверяют тесты

`npm test` гоняет разбор MIME (в том числе вложенные письма, Windows-1251 и KOI8-R), клиент IMAP на поддельном сервере, клиент SMTP на поддельном сервере, правила, шаблоны и клиент Gmail API. Секреты в этих тестах не настоящие.

## Поставить на iPhone через TestFlight

Делайте по порядку. Где написано «нажмите сами» — это сайт Apple, Google или вопрос в терминале. Программа сама туда не войдёт.

Идентификатор приложения уже задан: `es.verkvest.velliamail`. Если захотите другой, поменяйте его в `app.config.ts` до первой регистрации в Apple, потом его не переименовать.

### 1. Apple Developer, идентификатор

1. Откройте [developer.apple.com/account](https://developer.apple.com/account) под тем Apple ID, на котором оплачен Individual.
2. Certificates, Identifiers & Profiles → Identifiers → кнопка «+».
3. App IDs → App → Continue.
4. Description: `Vellia Mail`. Bundle ID: Explicit, `es.verkvest.velliamail`.
5. В списке возможностей включите Push Notifications. Register.

### 2. Карточка в App Store Connect

1. Откройте [appstoreconnect.apple.com](https://appstoreconnect.apple.com) → Apps → «+» → New App.
2. Платформа iOS, имя `Vellia Mail`, основной язык Russian, Bundle ID `es.verkvest.velliamail`, SKU `vellia-mail`.
3. Create. Поле Apple ID на странице App Information (слева General) — это число `ascAppId`. Оно понадобится при отправке, его можно вписать в `eas.json` в `submit.production.ios.ascAppId`, но первый раз программа спросит сама.

### 3. Учётная запись Expo и сборка

На компьютере, где лежит этот каталог:

```bash
npm install
npm install --global eas-cli
eas login
eas init
```

`eas login` откроет браузер, войдите в Expo или заведите аккаунт. `eas init` привяжет проект. Если он напечатает Project ID и не запишет его сам, вставьте в терминал перед сборкой:

```bash
export EAS_PROJECT_ID='скопированный-id'
```

Сборка для TestFlight:

```bash
eas build --platform ios --profile production
```

На вопросах про сертификат и профиль соглашайтесь, чтобы Expo создал их сам. Когда спросит Apple ID — введите почту разработчика и код двух факторов. Это и есть тот вход, который нельзя сделать за вас. Mac для этого не нужен.

Сборка идёт на серверах Expo. В конце будет ссылка на `.ipa`.

### 4. Отправить в TestFlight

Когда сборка стала зелёной:

```bash
eas submit --platform ios
```

Выберите свежую сборку. Снова может понадобиться Apple ID. Через десять–пятнадцать минут сборка появится в App Store Connect → TestFlight. Если Apple спросит про шифрование: приложение только ходит по TLS, своего шифра в нём нет. В настройках сборки это уже отмечено, вопрос может и не всплыть.

### 5. Установить на iPhone

1. На iPhone откройте App Store, установите приложение TestFlight от Apple.
2. Войдите в него тем же Apple ID, что и в Developer.
3. Vellia Mail будет во внутреннем тестировании. У Individual других внутренних испытателей нет: это вы сами.
4. Нажмите Install.

Дальше приложение живёт на телефоне. Новая сборка после `eas build` и `eas submit` придёт в TestFlight сама, её нужно принять в приложении TestFlight.

Пока идентификатор Google не вшит в сборку, Gmail через кнопку «Войти» не заработает. Пароль приложения Mail.ru заработает сразу. После того как вставите идентификатор Google, нужна ещё одна сборка: схема возврата из Google зашивается в приложение на этапе сборки.

## Подключить Gmail

Один раз в [Google Cloud Console](https://console.cloud.google.com).

1. New Project, имя `Vellia Mail`.
2. APIs & Services → Library → Gmail API → Enable.
3. APIs & Services → OAuth consent screen. Если спросят тип, выберите External. Имя приложения `Vellia Mail`, почта поддержки — ваша. Сохраните.
4. В согласии добавьте области: `https://www.googleapis.com/auth/gmail.modify`, `.../auth/userinfo.email`, `.../auth/userinfo.profile`, `openid`.
5. Test users → Add users. Впишите все четыре адреса Gmail, которыми будете пользоваться. Пока приложение в статусе Testing, войти может только этот список.
6. APIs & Services → Credentials → Create credentials → OAuth client ID → iOS. Bundle ID: `es.verkvest.velliamail`. Create и скопируйте Client ID, он кончается на `.apps.googleusercontent.com`.

Перед следующей сборкой:

```bash
export GOOGLE_IOS_CLIENT_ID='вставьте-client-id.apps.googleusercontent.com'
eas build --platform ios --profile production
eas submit --platform ios
```

Либо впишите то же значение вместо `process.env.GOOGLE_IOS_CLIENT_ID ?? ''` в `app.config.ts`. Идентификатор клиента не пароль, его можно хранить в файле. Секрет клиента Google для этого входа не нужен и в приложение класть его не надо.

На телефоне: Настройки → Добавить ящик → Gmail → Войти в Gmail. Каждый из четырёх ящиков — отдельный вход, в окне Google каждый раз выбирайте нужный аккаунт. Повторите четыре раза.

Если Google не отдаёт долгоживущий ключ, приложение напишет об этом. Тогда либо войдите ещё раз и согласитесь на доступ, либо подключите этот ящик как «Gmail, пароль приложения». Пароль приложения включается в настройках Google-аккаунта, в разделе безопасности, и только если включена двухэтапная проверка.

Пока согласие в статусе Testing, через семь дней Google может попросить войти снова. Для частного приложения отеля это нормальный запасной режим. Вывод согласия из Testing в Production требует проверки Google из‑за доступа к почте и для одного владельца обычно не нужен.

## Подключить Mail.ru и List.ru

1. Откройте [account.mail.ru](https://account.mail.ru) → Безопасность → Пароли для внешних приложений.
2. Создайте пароль с именем `Vellia Mail`. Обычный пароль от ящика сюда не вводите: Mail.ru его не примет.
3. В приложении: Добавить ящик → Mail.ru или List.ru. Адрес, имя, пароль приложения. Серверы уже подставлены: `imap.mail.ru:993` и `smtp.mail.ru:465`, оба по TLS. List.ru ходит через те же серверы.
4. «Проверить вход», затем «Сохранить».

Пароль попадает в Связку ключей и больше на экране не показывается. В базе писем его нет.

Чужой сервер — пункт «Другой сервер»: те же поля плюс адреса IMAP и SMTP.

## Уведомления

В Настройках → Уведомления можно разрешить фоновую проверку и показать пробное уведомление. Текст на экране повторяет ограничение iOS: система сама выбирает время.

Если позже поднимете сервер из папки `relay/`, впишите его адрес `https://...` и секрет в том же экране. Пустое поле секрета не стирает уже сохранённый. Как поднять сервер, написано в `relay/README.md`. Без него приложение законченное.

## Где что лежит

| Путь | Зачем |
| --- | --- |
| `src/app` | Экраны |
| `src/mail` | IMAP, SMTP, MIME, Gmail, правила, шаблоны |
| `src/platform` | Связка ключей, SQLite, сокет. В браузере вместо них заглушки |
| `test` | Поддельные IMAP и SMTP и остальные тесты |
| `relay` | Необязательный сервер уведомлений |
| `app.config.ts` | Имя, идентификатор Apple, идентификатор Google |
| `eas.json` | Профили сборки TestFlight |

Язык интерфейса переключается в настройках и запоминается на телефоне.
